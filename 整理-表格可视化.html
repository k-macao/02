3.3 MACD 策略

基础规则

  1. 01项目计算公式

    基础规则DIF = EMA12 − EMA26；DEA = EMA9(DIF)；页面使用国内双倍柱 MACD = 2 × (DIF − DEA)

  2. 02最低样本

    基础规则至少 36 根有效已收盘日线

  3. 03金叉

    基础规则金叉且 DIF、DEA 都在零轴上方 → 下一交易日观察入场

  4. 04持有

    基础规则多头排列且双线在零轴上方 → 持有

  5. 05退出 / 规避

    基础规则死叉或空头排列 → 退出 / 规避

  6. 06水下金叉

    基础规则零轴下方金叉只观察反弹

派生策略

  1. 01分支连续柱体收敛

    默认确定性口径连续 3 次同侧收敛；起点 H/价在此前最多 60 个柱体的 P10/P90

    作用 / 限制动能预警，不是确定底部

  2. 02确认底背离

    默认确定性口径最多 120 根、至少 45 根有效最低价；价格 / DIF 谷左右各 2 根，±3 根匹配

    作用 / 限制价格谷后第 5 根才定稿，不回填最低点

  3. 03布林回归

    默认确定性口径BB(20,2)，冻结前一日带，触下轨后收回轨内 + 动能修复 + 中轨平缓过滤

    作用 / 限制研究性震荡代理；强趋势沿上轨不自动卖

  4. 04周日共振

    默认确定性口径至少 35 个已结束周，周 DIF>DEA + 日金叉；仍需日双线水上才算顺势确认

    作用 / 限制日金叉与柱翻红为同一事件；残缺当前周排除

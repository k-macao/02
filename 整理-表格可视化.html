3.1 量化引擎分层

模块职责
providersYahoo / 东方财富日与周 K、成交、资金流等数据
macd_strategy市场库 / 已有日线 / 免费源编排、历史补足、MACD 交叉与零轴过滤
macd_derivatives连续柱体极值预警、确认底背离、布林回归、已定稿周日共振
featuresMOM、TRD、REV、VOL、FLOW 五因子与趋势特征
probability历史滚动重算、分桶、保序回归（PAVA）、逻辑回归校准
liquidity南北向成交、量能、Amihud 非流动性、CR5 / CR20 集中度及综合分
engine编排计算、推进式回测、预测留痕与后续结算
render结果渲染为 HTML，由流水线注入主题排版
阶段处理结果
① collect收集指数 / 个股日线、沪深港通成交与港股成交数据标准化数据序列
② features逐日计算五因子；每个时点只使用当时可得数据因子分数与特征
③ probability用历史样本校准概率，并进行滚动检验概率、区间与回测指标
④ liquidity计算成交量、资金流与市场深度流动性画像及有界概率修正
⑤ validate推进式回测；预测写入记录并于之后结算命中率、Brier 与预测复盘
⑥ decide综合概率、区间和趋势状态一句话预测概括

3.2 板块轮动量化策略

维度当前计算口径
技术面 35%映射港股等权；综合 20 / 60 日收益映射分与收盘价、MA20、MA60 趋势结构
资金面 35%A 股概念板块主力净占比与港股映射股资金组等权合成
基本面 10%正 PE-TTM / PB 的横截面低值分位代理
行业板块 10%A 股概念板块当日涨跌幅映射分 + 上涨家数宽度
事件驱动 10%近 72 小时全球头条、东财快讯、国家政策与港股新闻关键词计分
三策略投票策略
①MA20/MA60 多空排列
②20/60/120 日等权动量
③对恒指的 20/60 日超额收益象限（简化 RRG 代理）

3.3 MACD 策略

基础规则

项目基础规则
计算公式DIF = EMA12 − EMA26；DEA = EMA9(DIF)；页面使用国内双倍柱 MACD = 2 × (DIF − DEA)
最低样本至少 36 根有效已收盘日线
金叉金叉且 DIF、DEA 都在零轴上方 → 下一交易日观察入场
持有多头排列且双线在零轴上方 → 持有
退出 / 规避死叉或空头排列 → 退出 / 规避
水下金叉零轴下方金叉只观察反弹

派生策略

分支默认确定性口径作用 / 限制
连续柱体收敛连续 3 次同侧收敛；起点 H/价在此前最多 60 个柱体的 P10/P90动能预警，不是确定底部
确认底背离最多 120 根、至少 45 根有效最低价；价格 / DIF 谷左右各 2 根，±3 根匹配价格谷后第 5 根才定稿，不回填最低点
布林回归BB(20,2)，冻结前一日带，触下轨后收回轨内 + 动能修复 + 中轨平缓过滤研究性震荡代理；强趋势沿上轨不自动卖
周日共振至少 35 个已结束周，周 DIF>DEA + 日金叉；仍需日双线水上才算顺势确认日金叉与柱翻红为同一事件；残缺当前周排除

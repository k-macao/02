# 章鱼 AI · 打氧日报

> 每日上水，新鲜活泼。

一套自动采集公开市场与资讯数据、生成中文日报、检查新鲜度并推送到微信的 Python 流水线。默认使用 **归藏简洁主题（`guizang`）**；概率与策略以规则、量化合成为主，港股七日分析可选接入大模型。所有结果仅供参考，**不构成投资建议**。

## 快速开始

需要 Python 3.11+ 和 `requests`。只想生成本地日报时无需推送令牌；要推送到微信，先在本地环境设置 `PUSHPLUS_TOKEN`，或在 GitHub Actions 中配置同名 Secret。

```bash
cd /path/to/02
python3 -m pip install requests
python3 output/pipeline.py --no-push   # 先生成、不推送
python3 output/push.py                # 完整流程：采集 → 分析 → 生成 → 新鲜度检查 → 推送
```

| 产物 | 位置 | 用途 |
|---|---|---|
| 最新日报 | `output/latest.html` | 本地查看或推送使用 |
| 日期归档 | `output/daily_report_YYYYMMDD.html` | 按日期保存的完整日报 |
| 量化预测记录 | `output/quant_history.json`、`output/weekly_forecast.json`、`output/hk7_forecast.json` | 记录预测，并在目标交易日后按真实收盘结算 |
| 新闻与情绪记录 | `output/news_history.json`、`output/sentiment_history.json` | 支持跨日去重、政策窗口与情绪基线 |

## 内容口径与阅读提示

| 页面标记 / 数字 | 含义 | 阅读时注意 |
|---|---|---|
| **当天** | 来源内容日期与报告日一致 | 仍需结合栏目本身的统计窗口理解 |
| **非当天 / 滞后** | 内容日期早于报告日，页面会标出日期 | 滞后报价不计入核心指数均值，不应当作实时价格 |
| **今日抓取** | 今天采集到的前瞻日历快照，不代表事件今天已发生 | 不参与“当天内容”推送门禁 |
| **暂缺 / 未展示** | 来源或对应数据块没有可用内容 | 总结的“数据覆盖”会列出暂缺来源；不会用旧数据补位 |
| **概率与回测** | 根据历史数据或明确规则得到的统计结果 | 概率不是保证；样本不足时只报样本量，不下命中率结论 |
| **AI 研判 / 鲜鲜解读** | 基于本次页面数据规则合成的辅助说明 | 是阅读辅助，不是独立数据源，也不是投资建议 |

行情会带对应市场的 `as_of` 日期。若 Yahoo 行情落后，系统会用较新的独立行情基准核对；不能确认日期更新时不覆盖原值。标题情绪只依据资讯标题，不会从价格涨跌反推新闻观点。社区热度与观点未经核实，不等同于事实。

### 策略、情绪与量化预测

| 模块 | 主要口径 | 关键限制 |
|---|---|---|
| 策略研判 | 结合行情、A 股板块、榜单活跃度、资讯与频道观点；板块复合分使用价格 60%、资金流 30%、舆情 10%。 | 规则确定性合成，不依赖大模型 API；证据不足时栏目缺席。 |
| 政策因子 | 基于近 15 个自然日政策 / 宏观标题与官方政策，构建行业及大盘 PSI，并输出趋势分、影响行业与风险预算。 | 否定语境不计为有效触发；无相关信息时栏目缺席。 |
| 新闻情绪 | 对最近成交日 A 股、港股、美股成交量靠前的标的，按近 72 小时标题计算 DNS；MOM 使用近 3 / 20 个有评分日，ANV 比较当日条数与近 30 日基线。 | 无可归因标题时显示无评分或不展示；不以涨跌代替新闻情绪。 |
| 板块轮动量化策略 | 东方财富 A 股概念当前快照 + 本地白名单关键词对应的港股公司观察篮子；输出五维加权分及 MA 趋势、多周期动量、相对轮动三票。 | A/H 关系不是官方成分映射；数据缺项保留为缺失，未满足覆盖门槛不出总分；三策略票与加权分分开展示。 |
| 港股量化引擎 | 日线、五因子、概率校准、资金流动性与滚动回测；输出指数 / 个股概率、区间、流动性分和复盘记录。 | 只用预测时点可得数据；概率夹在 5%–95%；缺失因子不以 0 冒充中性。 |
| 七日走势预测 | 恒生指数未来 7 个交易日逐日表格，含累计概率、80% 区间、建议仓位与止损止盈参考；AI 七日港股分析作为可选子块。 | 预测先留档，目标交易日后再结算；类比样本必须已结算，并运行截断不变性自检。 |
| AI 七日港股子块 | 恒指、恒科、国企指数概率与依据。配置大模型后可在受限数据内生成研判，并披露量化基准、降级原因与数字溯源结果。 | 默认没有 API Key 时该子块缺席；可通过 `OCTOPUS_HK7_FALLBACK=1` 改为展示量化基准。模型输出偏离基准过大、数字无法溯源或出现绝对化措辞时回退。 |

量化特征包括：**MOM** 动量、**TRD** 趋势、**REV** 反转、**VOL** 量能和 **FLOW** 资金。概率校准、滚动样本外回测、预测留痕与日后结算都在页面或对应 JSON 中披露；预测结果用于研究参考，不代表确定性行情判断。

#### 【滚滚翻车鱼】板块轮动量化策略

这是一份**研究性观察篮子**，不是官方 A/H 板块映射，也不构成投资建议。概念池来自东方财富 `push2` 概念列表（`fs=m:90+t:3`，最多翻 5 页）；代码只按仓库内人工维护的白名单关键词，把命中的 A 股概念名称对应到若干港股公司观察篮子。未命中项保持未映射，不用名称相似度猜关系。概念库是当下快照，没有点时成分历史，因此当前实现不宣称历史回测或样本外有效性。

五维总分按固定权重计算。各维先按有效输入得到 0–100 分；缺失维度不补 0 或 50，只有至少 3 个维度、原始权重覆盖不少于 70% 时，才按可用权重重新归一化。报告同时列出每维有效样本数、可用权重与数据日期。

| 维度 | 当前计算口径 |
|---|---|
| 技术面 35% | 映射港股等权；综合 20 / 60 日收益映射分与收盘价、MA20、MA60 趋势结构。至少 2 只映射股有足够日线才计分。 |
| 资金面 35% | 把 A 股概念板块主力净占比（东方财富 `f62/f6`）与港股映射股资金组等权合成；港股组以 `f184` 为主，缺失时用 `f62/f6`，至少 2 只港股有数据才代表该组。 |
| 基本面 10% | 正 PE-TTM / PB 的横截面低值分位代理；参照池为本次有数据的**全部映射港股观察篮子**，不是同行业 peer，且不代表盈利质量。可比样本不足时缺失。 |
| 行业板块 10% | A 股概念板块当日涨跌幅映射分 + 上涨家数 /（上涨 + 下跌）宽度，两个可用输入等权。 |
| 事件驱动 10% | 仅扫描近 72 小时已有全球头条、东财快讯、国家政策与港股新闻的可验证日期标题；按概念 / 映射公司关键词和固定多空词表计分。无有效命中即缺失。 |

**三策略投票与五维加权分彼此独立：**① MA20/MA60 多空排列；② 20 / 60 / 120 日等权动量，至少两个周期同向才投票；③ 对恒指的 20 / 60 日超额收益象限。第三项是**简化 RRG 代理，不是标准 JdK RRG**。至少两套策略有效且至少两票同向，才给偏多 / 偏空；否则标为分歧、中性或数据不足。

## 新鲜度与推送规则

| 场景 | 处理方式 |
|---|---|
| 数据来源回退 | 每条注册的数据线有 1 个主源和 2 个备用源；主源无响应或正文无效时依次回退。实际使用的备用源会记入日志和总结。 |
| 当天内容检查 | 至少一个数据源抓到当天内容，日报才通过默认推送门禁。前瞻日历属于“今日抓取”快照，不能单独打开门禁。 |
| 当天检查未通过 | 默认不推送日报，但会发送纯文本检查告警；需要研究用状态报告时可用 `--allow-incomplete-push`。 |
| 无数据的栏目 | 不显示空栏目，也不拿历史数据冒充实时值；暂缺来源在“数据覆盖”中说明。 |
| 推送可恢复错误 | 网络异常、HTTP 429/5xx 或发送频繁等错误按 10 秒、30 秒、60 秒退避重试，最多 4 次；不可恢复错误立即失败。 |
| 推送仍失败 | 日报发送失败会尝试发送纯文本告警；推送或告警失败以退出码 1 结束，便于 Actions 标红。 |
| 单条内容超限 | 默认上限按 PushPlus 会员 100,000 字符配置；低于上限一页发送，超限则在栏目 / 完整标签边界拆分，续片重新带栏目头。默认最多 12 条、条间 2 秒，并按平台频率限制排队。 |

**账号额度请按实际情况设置**：PushPlus 文档列出的会员额度为 10 万字、实名用户为 2 万字。可用 `PUSHPLUS_MAX_CONTENT_CHARS` 覆盖默认值。设置 `PUSHPLUS_MULTIPART=0` 会关闭完整分条，改为安全截断并附完整版链接；磁盘归档仍保留完整报告。

| 指定输出 | `python3 output/pipeline.py -o custom.html` | 自定义报告路径 |
| 手动重新抓取并推送 | `python3 output/pipeline.py --manual` | 仍执行当天检查 |
| 强制推送 | `python3 output/pipeline.py --manual --force-push` | 当天检查未通过也推送；谨慎使用 |
| 推送已有报告 | `python3 output/pipeline.py --push-only [文件]` | 不带文件时选实际最新报告；仍执行新鲜度检查 |

| 方式 | 配置 / 操作 |

GitHub 定时任务可能受平台负载影响而延迟；若发送失败，工作流会失败退出，不会静默显示成功。

```text
output/
├── pipeline.py             # 核心流水线：采集、分析、生成、当天检验、推送

│   ├── probability.py      # 概率校准与推进式回测
│   ├── liquidity.py        # 资金流动性
│   ├── engine.py           # 量化编排、校验与留痕结算
│   ├── render.py           # 量化结果排版
│   └── sector_rotation.py  # A 股概念到港股观察篮子的轮动评分与三策略投票

├── daily_report_*.html     # 日期归档
└── latest.html             # 最新日报
```

### 量化引擎分层

| 模块 | 职责 |
|---|---|
| `providers` | Yahoo 日线与东方财富成交、资金流等数据 |
| `features` | MOM、TRD、REV、VOL、FLOW 五因子与趋势特征 |
| `probability` | 历史滚动重算、分桶、保序回归（PAVA）、逻辑回归校准 |
| `liquidity` | 南北向成交、量能、Amihud 非流动性、CR5 / CR20 集中度及综合分 |
| `engine` | 编排计算、推进式回测、预测留痕与后续结算 |
| `render` | 结果渲染为 HTML，由流水线注入主题排版 |

引擎内部的计算顺序与模块分层相互配合：

| 阶段 | 处理 | 结果 |
|---|---|---|
| ① collect | 收集指数 / 个股日线、沪深港通成交与港股成交数据 | 标准化数据序列 |
| ② features | 逐日计算五因子；每个时点只使用当时可得数据 | 因子分数与特征 |
| ③ probability | 用历史样本校准概率，并进行滚动检验 | 概率、区间与回测指标 |
| ④ liquidity | 计算成交量、资金流与市场深度 | 流动性画像及有界概率修正 |
| ⑤ validate | 推进式回测；预测写入记录并于之后结算 | 命中率、Brier 与预测复盘 |
| ⑥ decide | 综合概率、区间和趋势状态 | 一句话预测概括 |
